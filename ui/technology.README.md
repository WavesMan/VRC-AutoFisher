## 用户界面模块 (`ui`)

#### 1. **`main_window.py`**
   - **功能**: 主窗口界面，包含：
     - 钓鱼参数设置（蓄力时间、休息时间、超时重钓）
     - 时间管理面板：
       - 本地/世界时间切换
       - 洲/地区两级时区选择
       - 实时时间显示（精确到秒）
       - 应用/取消更改机制
     - 聊天文本发送功能（144字符限制）
     - 状态显示区域
   - **关键特性**:
     - 线程安全的UI更新
     - 实时时间显示与OSC通信分离
     - 完整的错误处理和用户提示
